# Learn by Naitik Here — static website

Framework-free export using semantic HTML, one shared `styles.css`, and vanilla `script.js`.

## Structure
- `index.html` — home
- `courses/` — catalog and four course pages
- `about/`, `faq/`, `contact/` — supporting pages
- `assets/` — local images and favicon

## Configuration
Replace the placeholder WhatsApp number, email, UPI, bank details, payment-proof URL, and QR image before accepting real enrollments.

The public pages intentionally do not show course fees. The enrollment panel reveals the selected fee only after valid learner details are entered.
